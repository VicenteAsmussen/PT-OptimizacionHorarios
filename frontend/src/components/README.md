# Componentes compartidos

Este directorio reúne componentes reutilizados por distintas funcionalidades. Los componentes propios de una funcionalidad permanecen junto a ella en [features/](../features/).

## Descripciones de la estructura inicial

Las carpetas `ui/` y `feedback/` solo contenían una descripción, sin implementación. Se retiraron y sus textos se conservan aquí:

| Carpeta retirada | Descripción original |
| --- | --- |
| `ui/` | Componentes básicos de interfaz reutilizables, como botones, inputs, tablas, tarjetas, badges y modales. |
| `feedback/` | Componentes para estados de carga, errores, mensajes vacíos, alertas y retroalimentación al usuario. |

Estas descripciones son referencias de la estructura inicial, no una lista de trabajo pendiente ni una indicación de dónde deben ubicarse los componentes actuales.
